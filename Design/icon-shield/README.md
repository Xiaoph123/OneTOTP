# OneTotp 盾牌图标

> 三个方案互不影响：`Design/icon/` 是第一套（倒计时环 + 1），本目录是盾牌方向。
> 本目录里同时保留了**素版**（最初那版，平涂细线）和**丰富版**（当前主推）。
> 全程**没有修改任何一行代码**，全部是新增文件。

---

## 1. 从素版到丰富版：做了哪些"加处理"

| | 素版 `-plain` | 丰富版（当前主推） |
| --- | --- | --- |
| 盾体 | 单色平涂（一个色 + 透明度） | **三段渐变**：`#6FA5FF → #1664FF → #0B41B8`，左上受光、右下沉下去 |
| 暗面 | 整体右移的淡色块，几乎看不出边 | **新月形硬边暗面**，只占右下一条弧带，边界清晰 |
| 边缘光 | 无 | **内缘边缘光**：沿内缩轮廓的一道亮带，向左下渐隐 |
| 轮廓线 | 40 细线 | 40 外轮廓 + 内缘光带，形成双层边缘 |
| 笔画 | 64 单色，圆头 | **76 加粗 + 白到 `#DCEAFF` 的向下渐变 + 下沉 10px 的投影**，笔画有了体积 |
| 观感 | 清爽、轻、极简 | 有光感、有层次，仍然干净 |

一句话：**不是变复杂了，是让每个面都承担了一点信息**——受光面/暗面/边缘光/投影，四层各司其职。

## 2. 赛璐璐的基因没有丢

动漫赛璐璐的三条规则仍然严格遵守：

| 规则 | 丰富版里的体现 |
| --- | --- |
| **平涂**：一个面一个色 | 渐变只是把"一个色"扩展成"一条色阶"，每个面本身仍是纯色，没有杂色噪点 |
| **硬边**：明暗交界干净 | 新月暗面是 `fill-rule="evenodd"` 切出来的硬边，没有一处模糊 |
| **恒定线宽** | 外轮廓 40 全程不变，转角 `stroke-linejoin="round"` |

### 暗面是怎么切的（这里踩过一个坑，值得记一笔）

第一版我用了一个看似聪明的做法：**把盾牌整块向右平移，裁切在盾牌内**当暗面。
结果发现——两个相同形状偏移一点点，交集几乎就是整个形状，于是**暗面盖住了 85% 的盾体**，渐变只剩下左边一条窄边。素版因为用的是低透明度所以看不出来，一旦换成不透明的深蓝，整个盾就变成一块黑。暗色版当时真的渲染成了一面黑盾。

改成 **evenodd 相减**就对了：

```
<path d="[盾牌] [盾牌]" fill-rule="evenodd"
      transform="scale(0.885) translate(-26,-26)" />
```

外轮廓减去「内缩 88.5% 并往左上偏移 26px」的同一个盾形，剩下的就是**右下一条新月形弧带**——宽度由 `inset` 和 `shift` 两个数字控制，交界线永远贴合盾牌轮廓。以后改盾形，暗面自动跟着走。

## 3. 造型规格

画布 **1024 × 1024**，透明底，纯几何路径，**不依赖任何字体**。

### 盾牌

```
M 358 208  H 666
A 96 96 0 0 1 762 304        ← 右肩圆角
V 516
C 762 648 676 760 512 846    ← 右下收至软尖底
C 348 760 262 648 262 516    ← 左侧对称回升
V 304
A 96 96 0 0 1 358 208  Z
```

外框 **500 × 638**，肩角半径 **96**，收腰 y=516，底尖圆滑。

### 几何参数

| 参数 | 值 | 作用 |
| --- | --- | --- |
| `lineW` | 40 / 34 | 外轮廓线宽 |
| `inset` | 0.885 | 新月暗面的内缩比例 |
| `shift` | 26 | 新月暗面的偏移量（决定暗面宽度） |
| `rimInset` | 0.955 | 边缘光所在的内缩位置 |
| `rimW` | 46 | 边缘光宽度 |
| 笔画宽 | 76 | 数字 1 |
| 笔画投影 | 下移 10px | 让笔画"浮"起来 |

### 数字 1

```
M 393.46 433.54  L 512 358  L 512 610
M 392 610        L 632 610
```
笔画宽 76、圆头圆角、旗与竖笔 45°。

### 小写 one（可选版本）

`o` / `n` / `e` 全部用笔画拼（圆环 / 两竖加圆肩 / 横杠加绕回圆弧），笔画宽 38。
**建议 ≥96px 使用**，32px 下三个字母会糊成一团。

## 4. 两个颜色版本

造型完全一致，只换色阶。

| | 亮色版 `-light` | 暗色版 `-dark` |
| --- | --- | --- |
| 用在哪 | 浅色界面 / 白色任务栏 | 暗色界面 / 深色任务栏 |
| 盾体渐变 | `#6FA5FF` → `#1664FF`（50%，品牌主色）→ `#0B41B8` | `#C6DBFF` → `#7FA8FF` → `#4668C4` |
| 新月暗面 | `#052B7D` @ 92% | `#1A2648` @ 85% |
| 内缘边缘光 | 白 95% → 40% → 0 | 白 95% → 40% → 0 |
| 外轮廓 | `#0A38A8` / 40 | `#D6E5FF` / 34 |
| 笔画 | 白 → `#DCEAFF` 渐变，投影 `#04205E` @ 80% | 白 → `#DCEAFF` 渐变，投影 `#16203C` @ 70% |

- 渐变的 **50% 锚点严格落在品牌主色 `#1664FF`**（tokens.css 的 `--primary-6` / `--color-primary`）。
- 暗色版的轮廓取了**浅色**（`#D6E5FF`），在深底上会读成一道发光边——这是深色界面里最有效的"立住形状"的手段。
- 两个版本**光源方向一致**（光从左上来、暗面在右下），明暗切换时不会有"光突然跑到另一边"的违和感。

## 5. 尺寸表现

| 尺寸 | 用在哪 | 表现 |
| --- | --- | --- |
| 512 / 256 | 宣传图、关于页 | 渐变色阶、新月暗面、边缘光三层都清晰 |
| 128 / 64 | 桌面快捷方式、商店 | 层次仍在，暗面与边缘光可辨 |
| **32** | Windows 任务栏 / 资源管理器 | 渐变与笔画体积仍在，是最小可用尺寸 |
| **16** | 通知区、菜单 | 收敛成一个带明暗的蓝色盾形——16px 的物理极限，属正常表现 |

## 7. 落地到应用里

`tauri.conf.json` 的 `bundle.icon` 引用的 5 个路径不用改，选一个色版放进 `develop/src-tauri/icons/` 即可：

```bash
# 先备份现有的默认图标（现在是 Tauri 默认的橙青色 Logo）
cp -r develop/src-tauri/icons develop/src-tauri/icons.bak

# 二选一
cp -r Design/icon-shield/tauri-light/* develop/src-tauri/icons/
# cp -r Design/icon-shield/tauri-dark/* develop/src-tauri/icons/

# 或者用 Tauri 官方生成器从任意 SVG 重新生成
npx tauri icon Design/icon-shield/oneTotp-shield-light-app.svg -o develop/src-tauri/icons
```

改完需要重新 `npm run tauri build` 才会打进安装包。

> 💡 `.ico` / `.icns` 是单个文件，无法按主题切换，桌面上只能选一个。
> 如果要在**应用内**跟着 `<html data-theme>` 切换，把这两个 SVG 放进前端资源即可——那部分需要改代码，我没有动。

## 8. 想继续调的话，改这几个数字就够

| 想改什么 | 改哪里 |
| --- | --- |
| 盾牌胖瘦 / 高矮 | `SH` 里的 `w`(500) / `top`(208) / `bottom`(846) |
| 肩角圆度 | `shoulder`(96) |
| 暗面宽度 | `inset`(0.885) 和 `shift`(26) |
| 边缘光宽度与强度 | `rimW`(46) 和 `rm` 渐变里的三个 opacity |
| 渐变深浅 | `bd` 渐变的三个 stop-color |
| 笔画粗细与厚度感 | `glyphSw`(76) 和 `glyphOffset`(10) |

所有参数都是 SVG 里的明文数字，没有压缩、没有转 path 化，直接手改即可。
