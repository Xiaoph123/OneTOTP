# OneTotp 盾牌图标 · 现代方向候选

> 赛璐璐（动漫）方向已废弃，这里是四个**主流现代**方向的候选，供挑选。
> 四个都满足：盾牌 + 1、只用两色、亮/暗两版、无描边无硬边阴影。
> 选定后我再把它做成正式交付（全套 .ico / .icns / 磁贴 + 说明文档）。

打开 **preview.html** 可以看全部尺寸在亮/暗背景上的实景。

---

## 四个候选

| | 文件名 | 做法 | 特点 |
| --- | --- | --- | --- |
| **A** | `candidate-A-soft-gradient-*.svg` | 透明底。盾体走品牌蓝三段渐变（`#5E96FF → #1664FF → #0A38A8`），左上角一层柔和径向高光，底下垫一层高斯模糊的柔和投影，无描边 | 最"现代 SaaS"的一版，有光感但不花，任何背景上都能用 |
| **B** | `candidate-B-duotone-*.svg` | 透明底。盾体纯色 `#1664FF` 平涂，白色笔画，无渐变、无阴影、无描边 | 最干净、最克制的两色版；接近 Linear / Stripe 的插画语言 |
| **C** | `candidate-C-negative-*.svg` | 圆角方形蓝底（渐变）＋纯白盾牌＋把 `1` 从盾牌上**镂空**（用 mask 挖掉，露出底色） | 负空间最有设计感，是标准 App 图标的形态 |
| **D** | `candidate-D-dimensional-*.svg` | 圆角方形蓝底＋白色盾牌（自身带极淡渐变＋柔和投影）＋品牌蓝 `1` | 立体感最强、最像成熟商业 App 的一版 |

### 暗色版怎么处理

- **A / B**：不是"变暗"，而是把色阶整体上移成亮蓝（`#7FA8FF` 系），保证在深色任务栏上立得住；B 的暗色版把 `1` 反相成深色，形成图标内部的对比。
- **C / D**：底衬换成深色（`#101827` / `#0F1726`），白盾继续承担识别。

---

## 我的建议

- 想要**透明背景、随处可用、有现代光感** → 选 **A**
- 想要**最简洁克制、纯两色** → 选 **B**
- 想要**标准 App 图标形态（带底衬）** → 选 **C** 或 **D**（C 更平面有设计感，D 更立体更商业）
